Giới thiệu về tôi

Xin chào! Tôi là Quàng Văn Công.

Tôi là sinh viên Công nghệ thông tin, yêu thích lập trình và khám phá những công nghệ mới.

Tôi đang học tập và thực hành HTML, CSS, JavaScript, Git và Docker để xây dựng những website hữu ích, thân thiện với người dùng.

Mục tiêu của tôi là không ngừng nâng cao kiến thức, rèn luyện tư duy lập trình và phát triển các dự án thực tế.

Kỹ năng của tôi

  • HTML
  • CSS
  • JavaScript
  • Git và GitHub
